# hello-git

开源软件通识 · 实验一：GitHub 平台项目协作实践

一个用于练习 Git 基本操作的小项目，借助一个 Python 问候脚本，
演示本地仓库管理、远程仓库同步、分支合并与冲突处理等完整流程。

## 目录结构

    hello-git/
    ├── README.md      项目说明
    ├── hello.py       示例脚本
    └── .gitignore     Git 忽略规则

## 运行方式

    python hello.py

## 协作说明

本项目用于课程实验，欢迎通过 Issue 提出建议，通过 Pull Request 提交改进。
基本协作流程：Fork 仓库 → 新建功能分支 → 提交修改 → 发起 Pull Request → 评审后合并。
提交信息建议采用 `feat:`、`fix:`、`docs:` 等前缀，便于追溯变更。
